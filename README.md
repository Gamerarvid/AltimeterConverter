# AltimeterConverter
This is an easy to use converter for converting between inHg and hPa. This was created with Microsoft FlightSimulator 2024 in mind.

How to use:
1. Start the script
2. Enter the number

General info:
- It will auto detect if you're inputing inHg or hPa by checking if the entered value is greater or less than 100 and convert it to the other unit.
- Type 'cls' to clear the screen
- Type 'exit' to exit the script
